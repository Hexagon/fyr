Offline Wikipedia on a Raspberry Pi

Put all of Wikipedia — and other Kiwix ZIM archives like Wiktionary or Stack Exchange — on a Raspberry Pi and read it from any phone, tablet, or laptop, with no internet connection.

Wikipedia is published as ZIM files by the Kiwix / openZIM project: a single compressed archive per wiki, with a built-in full article index. Fyr has a native ZIM reader built into its server, so a Raspberry Pi running Fyr can serve those archives to every browser on your network — alongside offline maps, ebooks, and a local AI assistant.

What you need#

  • A Raspberry Pi with a 64-bit OS. Fyr's images natively support linux/arm64, which matches Raspberry Pi OS 64-bit. A Raspberry Pi 4 or 5 is a good fit; a Pi 3B+ also runs 64-bit Raspberry Pi OS.
  • Storage sized for the archive. ZIM files range from a few hundred megabytes (a topic-focused wiki) to well over 100 GB (the complete English Wikipedia with images). For the large archives use a USB SSD or a large, fast microSD card.
  • Internet access once, to install Fyr and download the archive. After that, everything works offline.

Choose the right Wikipedia ZIM#

Kiwix publishes several variants of each Wikipedia language edition. Browse them at library.kiwix.org (the same source listed in Fyr's curated catalog). File names encode the variant:

VariantWhat it containsGood for
maxiFull articles with imagesThe closest thing to the real site, if you have the disk space
nopicFull articles, no imagesMost of the text at a fraction of the size
miniOnly the introduction of each articleSmall cards and quick lookups
Topic selectionsCurated subsets (for example medicine)Focused libraries on small storage

Kiwix also publishes ZIM archives of Wiktionary, Wikivoyage, Stack Exchange sites, and technical documentation such as DevDocs — Fyr reads them all the same way. If storage is tight, start with a nopic or mini edition and add more later.

Step 1: Install Fyr on the Raspberry Pi#

Install Fyr with the hosted installer script. It runs Fyr as a Docker container and remembers your options (port, data directory or volume, admin password) for later upgrades.

curl -fsSL https://fyr.guide/install.sh | sh

The full set of options — manual docker run, bind-mounting a USB drive as the data directory, and building from source — is in the installation guide. If the container exits with an illegal instruction error on an older board, reinstall with the compatibility image; the installer's --legacy shortcut picks the right one for your architecture:

curl -fsSL https://fyr.guide/install.sh | sh -s -- --legacy

When it finishes, open http://<pi-ip-address>:8080 from another device on the same network.

Step 2: Download the ZIM archive into Fyr#

Open Content Manager in Fyr and either paste the ZIM file's download URL to queue a server-side download, or upload a file you already have through the Local Imports panel (button or drag and drop). Files ending in .zim are routed to the books/ folder automatically.

  • Large archives take a while. If a multi-gigabyte download times out, raise Settings → Downloads → Request timeout (seconds) and queue it again.
  • If you mounted a host directory as Fyr's data directory, you can also copy the .zim file straight into <data-dir>/books/ — for example from a USB drive — without downloading it through the browser.
  • When Fyr is password-protected (FYR_ADMIN_PASSWORD), log in as admin first; guests cannot use Content Manager.

Step 3: Open and search Wikipedia in the Library#

Go to Library (the Books page) and select the .zim file. Fyr opens it in its unified reader shell: use the search box in the reader toolbar to find articles by title or path, and follow links inside articles without leaving the page. Archive styles are used as published, so articles look like the original wiki.

Step 4: Share it with every device#

Any device on the same network can now open Fyr in a browser — no app installs. For somewhere without a router (a cabin, a classroom, a vehicle), turn the Pi into its own Wi-Fi hotspot as described in the off-grid knowledge server guide. Phones and tablets can also add Fyr to the home screen as an app.

Lock it down for guests or a kiosk#

For a shared or public deployment, choose one of Fyr's access modes:

  • FYR_ADMIN_PASSWORD — everyone can read; only the admin can download, import, delete, or change settings.
  • FYR_READONLY=true — strict read-only mode for kiosks and public libraries: every change is refused by the server and no filesystem paths or disk capacity are revealed.

Both can be set with the installer's --admin-password and --readonly arguments; see the access control section of the User Manual.

Troubleshooting#

  • The archive is not listed: confirm the file ends in .zim and sits in books/ under your data directory, then refresh the browser.
  • The ZIM view does not load: check the server status on the Overview page and retry opening the archive.
  • Content disappeared after a restart: make sure the /data volume or bind mount is still attached to the container.

More fixes are in the User Manual's troubleshooting section.
