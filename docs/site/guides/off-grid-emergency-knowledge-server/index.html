Build an off-grid emergency knowledge server

A low-power Raspberry Pi that broadcasts its own Wi-Fi network and serves maps, encyclopedias, manuals, and a local AI assistant to any phone — when the internet, the cell network, or the grid is down.

Updated 2026-10-26 · 4 min read · Applies to Fyr v0.5.2

Preparedness is mostly about having the right information when you cannot look it up. This guide combines Fyr's pieces into a single box: offline maps, a reference library, a local AI assistant, and offline utilities, served over a Wi-Fi hotspot so that any phone or laptop in range can use it from a browser. Prepare it while you still have internet; afterwards it needs only power.

Hardware checklist#

  • Raspberry Pi with built-in Wi-Fi (3B+ or newer) running a 64-bit, Debian-based OS with NetworkManager — the default on Raspberry Pi OS Bookworm. A Pi 5 with 8 GB RAM gives you room for a larger AI model.
  • Storage: a USB SSD or large microSD card. Budget space for each item on the preload list below.
  • Power: an official power supply for home use, plus a battery pack or a small solar setup sized for your Pi model for off-grid use.
  • Optional: a spare SD card with a cloned image, stored separately, as a backup.

Step 1: Install Fyr#

With the Pi online, run the hosted installer:

curl -fsSL https://fyr.guide/install.sh | sh

The installer runs Fyr as a Docker container that restarts automatically on boot and listens on all interfaces. Pass --admin-password to protect management features and --data-dir to keep content on a USB drive; both are remembered for upgrades. See the installation guide for the manual docker run command and bind-mounting a USB drive. On older boards, use --legacy if the container fails with an illegal instruction error.

Step 2: Preload the content#

Use Content Manager to queue downloads or import files. A practical starting list:

Repair, gardening, and how-to booksPublic-domain EPUBs from Standard Ebooks and Project Gutenbergbooks/

Offline installers, drivers, checksum listsWhatever your devices need to be rebuiltmisc/

Downloads are routed to the right folder by file extension. Fyr itself also ships offline Tools: unit converters (length, mass, temperature, volume, pressure, energy, and more) and text encryption, encoding, and checksum utilities.

Step 3: Turn the Pi into a Wi-Fi hotspot#

Create the hotspot with NetworkManager (replace Fyr and offline-fyr with your preferred SSID and password):

sudo nmcli device wifi hotspot \
  ifname wlan0 \
  con-name fyr-hotspot \
  ssid "Fyr" \
  password "offline-fyr"

Enable the hotspot to start automatically on every boot:

sudo nmcli connection modify fyr-hotspot connection.autoconnect yes
sudo nmcli connection modify fyr-hotspot connection.autoconnect-priority 10

Bring it up immediately without rebooting:

sudo nmcli connection up fyr-hotspot

Devices that join the Fyr network reach the server at http://10.42.0.1:8080, the default hotspot gateway address assigned by NetworkManager. If the Pi is also plugged into Ethernet, NetworkManager shares that connection through the hotspot when it is available. The same steps are on the Platform Setup tab of the installation guide.

Step 4: Lock it down for shared use#

If other people will use the box, set an admin password (installer --admin-password, or FYR_ADMIN_PASSWORD): guests can read, browse maps, and chat with the assistant, while downloads, imports, deletions, and settings need an admin login. For a public kiosk where nothing should ever change, reinstall with --readonly (FYR_READONLY=true), which blocks every change on the server and hides storage details.

Step 5: Test it offline — before you need it#

Unplug Ethernet and disable any upstream Wi-Fi, reboot, then connect a phone to the hotspot and walk through the checklist:

  • The hotspot appears after boot and http://10.42.0.1:8080 opens.
  • Maps render at street level for your area, and Wikipedia articles open and search.
  • The AI assistant loads its model and answers within an acceptable time.
  • On the phone, add Fyr to the home screen so it opens like an app.

Repeat the test after each upgrade. To update Fyr while you have internet, re-run the installer with update; your settings and content are preserved.

curl -fsSL https://fyr.guide/install.sh | sh -s -- update

Keeping it useful#

  • Refresh maps and ZIM archives every few months; Kiwix and the map sources publish new dated builds regularly.
  • Keep a copy of your data directory on a second drive so a failed card does not take the library with it.
  • Print a card with the network name, password, and address and keep it with the device.
