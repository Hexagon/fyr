Build a self-hosted offline maps server

Serve OpenStreetMap vector and raster maps from PMTiles or MBTiles files on your own hardware, and browse them from any device — without a tile server, map API key, or internet connection.

Online map apps fetch tiles from someone else's server. An offline maps server keeps the tiles on your own disk instead. Fyr reads the two common single-file tile formats directly:

  • PMTiles — a single-file archive designed to be read with HTTP range requests. Fyr's browser map reads .pmtiles files directly, without a tile server process.
  • MBTiles — a SQLite database of tiles. Fyr serves .mbtiles tile by tile through its built-in tile endpoint.

Both vector and raster archives work, and the map renders in the browser with MapLibre, so every phone, tablet, and laptop on the network gets a full interactive map with nothing to install.

Step 1: Install Fyr#

Any Linux, macOS, or Windows machine with Docker works, including a 64-bit Raspberry Pi. The quickest route is the hosted installer:

curl -fsSL https://fyr.guide/install.sh | sh

On Windows, use irm https://fyr.guide/install.ps1 | iex in PowerShell. Manual Docker commands and data-directory options are in the installation guide. Make sure other devices can reach Fyr: the installer and the documented docker run command bind to all interfaces (FYR_HOST=0.0.0.0).

Step 2: Get map data for your region#

You have two well-trodden options, both listed in Fyr's curated content catalog.

Option A: download a ready-made PMTiles extract#

BBBike publishes pre-generated OpenStreetMap extracts for many cities and regions, including PMTiles files in the Shortbread vector schema. Download the .pmtiles file for your area — it is ready to use as-is.

Option B: cut your own region with the pmtiles CLI#

Install the pmtiles command-line tool, find the latest dated planet build at maps.protomaps.com/builds, and extract a bounding box. The tool only downloads the tiles inside your box:

pmtiles extract https://build.protomaps.com/<YYYYMMDD>.pmtiles sweden.pmtiles --bbox=4.7,55.0,24.2,69.1 --maxzoom=15

A low-zoom world basemap is a good companion for the overview levels:

pmtiles extract https://build.protomaps.com/<YYYYMMDD>.pmtiles world.pmtiles --bbox=-180,-85.0511,180,85.0511 --maxzoom=8

The --bbox order is west,south,east,north in degrees. Each extra zoom level roughly quadruples the tile count, so lower --maxzoom if the file gets too large for your storage; street-level detail generally needs zoom 14–15.

Already have MBTiles?#

Existing .mbtiles archives — vector or raster — can be used as they are.

Step 3: Load the maps into Fyr#

In Content Manager, paste a download URL or use Local Imports to upload the file. .pmtiles and .mbtiles files are routed to the maps/ folder automatically. With a bind-mounted data directory you can also copy files straight into <data-dir>/maps/.

Step 4: Open the map#

Go to Maps, choose an archive in the map picker, and pan and zoom as usual. Nothing leaves your network: the browser reads tiles from Fyr only.

Add points of interest#

Fyr also stores POI layers. Put GeoJSON (.geojson), FlatGeobuf (.fgb), or geo .json datasets in the poi/ folder — useful for shelters, water points, trailheads, or anything you export from your own GIS tools.

Storage and hardware tips#

  • Map archives are read in place, so a Raspberry Pi with a USB SSD is plenty for a country-sized extract.
  • Keep the ARM board's memory and storage limits in mind when loading very large map or ZIM archives together.
  • Pair maps with a Wi-Fi hotspot to have a navigable map available to every phone in a cabin, boat, or field camp.

Troubleshooting#

  • The map is not listed: check that the file ends in .pmtiles or .mbtiles and is in maps/, then refresh.
  • A URL download stops partway: increase Settings → Downloads → Request timeout (seconds) and queue it again, or download the file elsewhere and import it.

See the Maps section of the User Manual for details.
